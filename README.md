Bitcoin Market Sentiment Analysis

## Overview
This project analyzes the relationship between Bitcoin market sentiment and trader performance using:

- Bitcoin Fear & Greed Index Dataset
- Hyperliquid Historical Trader Dataset

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Steps Performed
1. Data Loading
2. Data Cleaning
3. Date Conversion
4. Dataset Merging
5. Exploratory Data Analysis
6. Visualization
7. Insights Generation

## Key Findings
- Traders performed better during Greed periods.
- Trading activity increased during Greed and Extreme Greed.
- Win rates were higher during positive market sentiment.
